# Registry contracts: 0.x vs 1.x

`ScopedElementsMixin` supports two versions of the scoped custom element registry model, because two
of them exist in the wild. This page is the reference for what differs, and what to look for when
code breaks in one of them.

|                    | 0.x                                                                                                             | 1.x                                                                                                                                   |
| ------------------ | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| who implements it  | `@webcomponents/scoped-custom-element-registry@0.0.10` (what is on npm today); `@open-wc/scoped-elements` v2/v3 | native Chromium 133+; the redesign under review in [webcomponents/polyfills#668](https://github.com/webcomponents/polyfills/pull/668) |
| the scope          | the shadow root itself                                                                                          | a first-class `CustomElementRegistry`                                                                                                 |
| handover           | `attachShadow({ customElements: registry })`                                                                    | `attachShadow({ customElementRegistry: registry })` (the redesign also accepts `registry` as an alias)                                |
| creation           | `shadowRoot.createElement(tag)`, `shadowRoot.importNode(node, deep)`                                            | `document.createElement(tag, { customElementRegistry })`, `document.importNode(node, { customElementRegistry })`                      |
| read back          | `shadowRoot.customElements`                                                                                     | `element` / `document` / `shadowRoot` `.customElementRegistry`                                                                        |
| extra registry API | —                                                                                                               | `getName(tag)`, `initialize(node)`                                                                                                    |

Detection lives in `packages/ui/components/core/src/ScopedElementsMixinV4.js`:
`supportsScopedRegistryV0()`, `supportsScopedRegistryV1()` and `supportsScopedRegistry()`.

## Two rules that are not obvious

**0.x takes precedence over 1.x.** The 0.x polyfill replaces `window.customElements` and
`window.CustomElementRegistry` with its own classes, but it leaves the _native_ 1.x accessors in
place. So a browser with native support _and_ the 0.x polyfill is a 0.x environment: detection checks
for `ShadowRoot.prototype.createElement` first and reports "1.x = false" when it is there. Detection
never _reads_ the `customElementRegistry` accessor on a prototype (that throws "illegal invocation").

**Never send more than one spelling of the registry option.** A browser with native 1.x support
_validates_ the `customElementRegistry` member of `ShadowRootInit`, and a registry created by the 0.x
polyfill is not a native `CustomElementRegistry`:

```
TypeError: Failed to execute 'attachShadow' on 'Element': Failed to read the
'customElementRegistry' property from 'ShadowRootInit': Failed to convert value to
'CustomElementRegistry'
```

The unknown spellings (`customElements`, `registry`) are ignored by dictionary conversion, which is
exactly why sending all three fails: the known one is the one it validates. `attachShadow` therefore
sends only the spelling of the detected version.

## Breaking APIs to look for

| surface                                                                                                                                                                                                | 0.x                                                                                                     | 1.x                                                                                                                                                                                       | symptom when missed                                                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ShadowRoot.prototype.createElement` / `.importNode`                                                                                                                                                   | installed by the polyfill                                                                               | gone                                                                                                                                                                                      | `TypeError: ... is not a function`, or silently unscoped                                                                                                                  |
| `attachShadow({ customElements })`                                                                                                                                                                     | the way                                                                                                 | not read, passed to native and ignored → the root gets the document's registry                                                                                                            | no scoping, and no error                                                                                                                                                  |
| `shadowRoot.customElements`                                                                                                                                                                            | the read-back                                                                                           | `customElementRegistry` on element/document/shadowRoot                                                                                                                                    | `undefined` registry                                                                                                                                                      |
| `new CustomElementRegistry()`                                                                                                                                                                          | the shim class — must never enter a native `customElementRegistry` option                               | native-shaped                                                                                                                                                                             | `Failed to convert value to 'CustomElementRegistry'`                                                                                                                      |
| `define` / `get` / `whenDefined` / `upgrade`                                                                                                                                                           | present                                                                                                 | present                                                                                                                                                                                   | —                                                                                                                                                                         |
| `getName(tag)`, `initialize(node)`                                                                                                                                                                     | absent                                                                                                  | new in 1.x; `initialize` only assigns to `null`-registry nodes and a node's registry cannot change once set                                                                               | subtree never scoped                                                                                                                                                      |
| `document.createElementNS(ns, tag, {customElementRegistry})`, `document.importNode(node, { selfOnly, customElementRegistry })`                                                                         | absent                                                                                                  | new options. **There is no 3-argument `importNode(node, deep, options)`** — the boolean _is_ the options argument, so a third argument is silently ignored and the copy is never upgraded | clones resolve against the wrong registry                                                                                                                                 |
| declarative shadow DOM attributes                                                                                                                                                                      | `shadowrootcustomelementregistry`                                                                       | `customelementregistry` / `scopedcustomelementregistry`, plus the polyfill-only `polyfill-*` spellings                                                                                    | declarative roots in scoped trees stay unscoped                                                                                                                           |
| `innerHTML` setters, `insertAdjacentHTML`, `Range.cloneContents/extractContents/insertNode/surroundContents/createContextualFragment`, `Node.cloneNode`, `document.adoptNode`, `Element.setHTMLUnsafe` | creation-context scoping                                                                                | registry **preservation** across moves, and different template-contents rules                                                                                                             | an element resolves against a different registry than before after a move or clone                                                                                        |
| `:defined`                                                                                                                                                                                             | matches only defined                                                                                    | the polyfill also matches not-yet-customized                                                                                                                                              | wrong CSS states; use `:is(:not(:defined), :state(polyfill-undefined))`                                                                                                   |
| `formAssociated`                                                                                                                                                                                       | the old stand-in claims it for the **whole tag**, so it leaks to every version                          | decided per tag name, **first definition wins**                                                                                                                                           | fields silently missing or empty; see the form-associated page                                                                                                            |
| loading                                                                                                                                                                                                | no-ops if `ShadowRoot.prototype.createElement` already exists (so it cannot install after the redesign) | no-ops unless `inUse`, refuses a second load via `loaded`                                                                                                                                 | the script quietly does nothing                                                                                                                                           |
| `window.customElements`, `window.CustomElementRegistry`, `window.HTMLElement`                                                                                                                          | replaced                                                                                                | replaced                                                                                                                                                                                  | stale references and constructor comparisons; `@open-wc/scoped-elements` v3 additionally pushed `window.scopedElementsVersions`, which #4 dropped (no usage in this repo) |
